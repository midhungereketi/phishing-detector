# PhishGuard browser extension (Chrome / Edge, Manifest V3)

1. For the hosted app, download its ZIP from Protection: its API address is configured automatically. You can also run `python scripts/package-extension.py` from the repository to create `output/extension/PhishGuard-Chrome-Demo.zip` for the hosted demo. For a local installation using the repository `extension` directory, keep the Python backend running at `http://127.0.0.1:8000`.
2. Open `chrome://extensions` or `edge://extensions`, enable Developer mode, choose **Load unpacked**, and select this `extension` directory (or unzip the app download first).
3. For local/custom server setup, copy the extension ID. Add `PHISHGUARD_EXTENSION_ORIGINS=chrome-extension://YOUR_ID` to the project `.env` if your browser requires CORS preflight, then restart the API. Only this configured origin is allowed; no wildcard origins.
4. Sign in to PhishGuard, open **Protection**, generate a 30-day pairing token, and paste it in the extension popup. Tokens grant only URL checks and reading your own blocklist. They cannot access scan history, email contents or account settings.
5. Click **Sync blocklist**. Dynamic rules persist while the backend is offline and cover exact hosts (not subdomains), including typed navigation. Up to 1,000 hosts are supported. Sync runs each minute while the browser is running.

After pairing, ordinary web-link clicks are paused until the configured backend classifier replies. Low risk proceeds; medium/high or failed checks show a warning. Before pairing, links behave normally. The user can explicitly override a warning once, except personal blocks. This is a research prototype: content scripts do not cover the address bar, forms, scripted navigation, context-menu actions, browser-internal pages or every frame/context. Site scripts can interfere. Only synced blocklist rules provide pre-request blocking of known hosts. Disabling protection or disconnecting removes those rules.

Clicked URLs, including queries, go to the **configured PhishGuard backend** (the hosted app for its downloaded ZIP, or localhost for the repository extension). The extension does not run external reputation/network checks or store browsing history. The popup's current-tab check is explicitly initiated. Pairing tokens stay in trusted extension storage, expire after 30 days, and can all be revoked from Protection. Revocation prevents future server access; an already-synced local rule stays until disconnect, protection disable, removal or a successful sync.

The hosted extension privacy notice is at https://phishing-detector-pink.vercel.app/extension-privacy.html. The ZIP can be loaded unpacked for a free classroom demonstration. A Chrome Web Store listing requires the developer registration fee and Google's review; preparing a ZIP does not publish it.
